# Sistema de Compras

Este repositório contém uma atividade desenvolvida em **sala de aula** para a disciplina de **Sistemas de Informação**.

O projeto tem como objetivo praticar o desenvolvimento de um sistema de compras, utilizando conceitos de programação, banco de dados e operações de **CRUD**.

## 📚 Sobre a atividade

A atividade consiste no desenvolvimento de um cadastro de produtos contendo:

* ID
* Nome
* Valor
* Estoque

O sistema deverá permitir as operações de:

* Salvar produtos
* Consultar produtos
* Editar produtos
* Excluir produtos

## 🛠️ Tecnologias

* Java
* JSF
* PostgreSQL
* NetBeans

## 🎓 Finalidade

Projeto desenvolvido exclusivamente para **fins acadêmicos**, como parte das atividades realizadas em sala de aula.
